# Vườn Giống Quý Bình

Website bán cây giống Vườn Giống Quý Bình.

- Trang chủ: `index.html` (mở https://tintamquy.github.io/vuon-giong-quy-binh/ sau khi bật GitHub Pages)
- 5 trang cây: chà là, nhàu, cà gai leo, đinh lăng, khô nhung (điều hướng bằng #cay/...)
- Form đặt hàng: Google Forms (prefill), thanh toán: COD / chuyển khoản Agribank (QR)
